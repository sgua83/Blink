# 《B 语言源码分析》阅读资料

[书稿](../B语言源码分析.md) · [手机 PDF](../pdf/B语言源码分析-手机阅读版.pdf) · [标准 PDF](../pdf/B语言源码分析.pdf)。

正文沿当前编译器和执行框架解释底层知识；源码版本索引.json只保留现行文件哈希及节选位置，历史构建、运行及交付结果保存在P4双台账。

主线使用已有的 [map.b](../lessons/map.b) 和 [map.h](../lessons/map.h)，没有另建教学总入口。构建、检查、代码导出与 CPU/GPU 执行命令均在第一章。`figures/compiler-*.svg` 是配套原理图与基于真实输出重排的运行记录图，不能当作操作系统终端截图。

源码节选及行号随现行实现更新，使用返回类型函数定义、target 执行位置和 blc -c／bllink 两个正式阶段。普通 CPU 应用、原生调用与有限独立模块已有实现；完整模块／资源契约、一般异步应用、跨平台 CPU 及基础库等缺口分别说明。实际构建、原生结果与交付分别记录于P4双台账。
