# 《B 语言源码分析》阅读资料

[书稿](../B语言源码分析.md) · [手机 PDF](../pdf/B语言源码分析-手机阅读版.pdf) · [标准 PDF](../pdf/B语言源码分析.pdf)。

全书二十八章，以已提交的 Blink P4 CL13062 为分析对象，先解释关联底层知识，再阅读真实核心源码。源码节选保留原函数名与位置；`源码版本索引.json` 记录完整文件 SHA256、节选行范围、Release 原生运行结果与编译导出。

主线使用已有的 [map.b](../lessons/map.b) 和 [map.h](../lessons/map.h)，没有另建教学总入口。构建、检查、代码导出与 CPU/GPU 执行命令均在第一章。`figures/compiler-*.svg` 是配套原理图与基于真实输出重排的运行记录图，不能当作操作系统终端截图。

本书解读该版本已经存在的编译器与执行框架。独立应用入口、跨平台 CPU 及基础库等未完成能力在书中明确区分，不把未来语法写成当前功能。后续版本请结合实际源码与 Docs/Issues.md 阅读。
