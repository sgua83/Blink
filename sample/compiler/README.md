# 《B 语言源码分析》阅读资料

[书稿](../B语言源码分析.md) · [手机 PDF](../pdf/B语言源码分析-手机阅读版.pdf) · [标准 PDF](../pdf/B语言源码分析.pdf)。

全书二十八章，按本轮修订时已提交的 Blink P4 CL13553 解释当前实现，先讲关联底层知识，再阅读真实核心源码。源码节选保留原函数名与位置；`源码版本索引.json` 记录完整文件 SHA256、节选行范围、Release 原生运行结果与编译导出。

主线使用已有的 [map.b](../lessons/map.b) 和 [map.h](../lessons/map.h)，没有另建教学总入口。构建、检查、代码导出与 CPU/GPU 执行命令均在第一章。`figures/compiler-*.svg` 是配套原理图与基于真实输出重排的运行记录图，不能当作操作系统终端截图。

本版重取全部五十三处节选并更新行号与索引，使用返回类型函数定义、target 执行位置和 blc -c／bllink 两个正式阶段。普通 CPU 应用、原生调用与有限独立模块已有实现；完整模块／资源契约、一般异步应用、跨平台 CPU 及基础库等缺口分别说明。本轮 Release 构建、map 的 CPU／GPU 原生结果和普通应用编译／链接／执行已记录。
