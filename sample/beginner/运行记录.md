# 《B 语言编程》实际运行记录

## 独立应用

使用已提交 Blink CL13085 的独立 Release 构建。十三个正式例子分别经 blc build-exe 编译，再直接启动生成的 exe，读取标准输出与退出码；所有实际输出均与书稿对应，退出码均为零。

`应用运行记录.json` 保存每例标准输出、源码 SHA256、exe SHA256、编译器版本与 SHA256。该记录不表示后续开发版本已具有相同全部能力。

## 并行计算模块

numbers、stages、totals、shape、scores 使用同一正式版本 blrun 的 CPU 路径重新执行，stages 和 scores 同时执行 GPU 路径。结果、完整 BLDATA word 与 SHA256 同样保存在 JSON。小输入只用于学习语法与核对结果，不作为性能对照。

运行图由真实输出重排，不作为操作系统终端截图。临时编译器副本、教学 exe、排版脚本与编译导出在本次交付后清除，保留正式源码、书稿、PDF 与必要原始输出。
