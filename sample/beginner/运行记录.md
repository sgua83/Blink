## 独立并行应用（CL13172）

本轮使用已提交源码的 Release 产物 `B:/BLanguage/target/release/blc.exe`，在 Gua／192.168.10.5 编译八个应用，随后直接启动生成的 exe，读取真实标准输出、标准错误和退出码。编译前确认主工作区 crates 与已提交来源一致，未改动编译器。运行时没有向 exe 提供源码、容量、输入或输出文件参数。

| 应用 | 设备与内容 | 完整标准输出，斜线表示换行 |
|---|---|---|
| numbers_serial | CPU 顺序循环 | `2 / 4 / 6 / 8` |
| numbers | CPU parallel | `2 / 4 / 6 / 8` |
| stages | CPU 两个阶段 | `3 / 5 / 7 / 9` |
| totals | CPU 扫描与归约 | `0 / 1 / 3 / 6 / 10` |
| stages_gpu | GPU 两个阶段，显式传输 | `3 / 5 / 7 / 9` |
| shape | CPU 固定形状实例 | `1 / 2 / 3 / 4` |
| scores | CPU 成绩与求和 | `45 / 50 / false / 60 / 65 / true / 75 / 80 / true / 90 / 95 / true / 290` |
| scores_gpu | GPU 同一成绩算法，显式传输 | `45 / 50 / false / 60 / 65 / true / 75 / 80 / true / 90 / 95 / true / 290` |

八个应用均退出零，标准错误为空。CPU 与 GPU 的 stages 结果、scores 全部记录与总和一致。JSON 的 parallel_applications 保存本轮版本、真实编译和运行命令、编译器／源码／exe／配套 DLL SHA256 与完整输出；cases 与 compute_cases 保留上一轮结果，不冒充重新执行。

四项输入用于学习语法和核对每一步，不作为效率比较。运行图按真实输出整理，不是操作系统终端截图。临时教学 exe、配套执行库、排版和核对脚本在交付后清理；正式 B 源码、书稿、两份 PDF 和必要原始输出保留。

## 小数与坐标直接显示（CL13181）

第四章 types 与第十一章 vectors 使用已提交 CL13181 来源的 Release 编译器重新构建为 exe，再直接运行。这两个程序均只产生 exe，无需 Blink 配套执行库、数据文件或另写宿主。

| 应用 | 完整标准输出，斜线表示换行 |
|---|---|
| types | `3 / -3 / true / 21.5 / 3.5` |
| vectors | `1 / 3 / -2 / 1` |

两例均退出零，标准错误为空。当前书稿分别显示真实温度、小数除法、移动和旋转后的坐标分量，不再以真假判断代替数字。JSON 的 floating_applications 保存最新编译器、源码与 exe SHA256、真实命令及完整标准输出；此前 cases 中这两例的真假输出保留为 CL13085 历史结果。
