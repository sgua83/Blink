本轮使用已提交源码的 Release 产物 `B:/BLanguage/target/release/blc.exe`，在 Gua／192.168.10.5 编译八个应用，随后直接启动生成的 exe，读取真实标准输出、标准错误和退出码。编译前确认主工作区 crates 与已提交来源一致，未改动编译器。运行时没有向 exe 提供源码、容量、输入或输出文件参数。

## 编译与链接分离后的本版记录

本版使用本次解耦实现的 Release blc 与 bllink，在 GUA／192.168.10.5、Windows x64 上重新运行二十一个正式应用。每例分别执行 blc -c 生成 AMD64 COFF obj、bllink 生成 exe、直接启动 exe，完整输出与正文一致，退出码全部为零，标准错误为空。GPU 为 AMD Radeon RX 9070 GRE。

另将 start、stages、stages_gpu 的目标文件和 bllink 单独放入没有 B 源码的目录，子进程 PATH 只保留 Windows 系统目录；三个应用仍可链接并实际运行。链接阶段没有调用 blc、Cargo 或 rustc。含执行框架的目标文件使用已安装的 MSVC 本机链接器与 Windows SDK。

算法 DLL 另完成 C、C++、Rust CPU／GPU 调用；Rust 原生 crate API 也完成 CPU／GPU 调用，四个输出均为 3、5、7、9。Rust crate 消费与源码工程相同的 ThinLTO／优化配置，DLL ABI 未改成仅供一种宿主使用。

JSON 的 compile_link_applications 保存本轮完整编译、链接、运行命令、工具与编译器源码 SHA256、目标文件和 exe SHA256，以及二十一个应用的标准输出和退出码。前面的 CL13085、CL13172、CL13181 记录继续作为历史结果保留。书中命令使用 target 下的普通输出位置，原始核对在 Saved/CompileLinkBook 的独立临时目录执行。
