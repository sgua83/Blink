# Call B from Rust

[Back to getting started](GettingStarted.en.md#first-dll) · [中文](RustInterop.md)

Pass four numbers from Rust to a B function that computes `value * 2 + 1`, then read the result in the original array. This tutorial covers only the Rust host.

## Prepare

Complete [installation](GettingStarted.en.md#install), including Rust MSVC and the Windows build tools needed to generate a compute DLL. Open **x64 Developer PowerShell**, create an empty folder, and work there. No repository checkout is needed.

## Write the B computation

Save both files in that folder:

**map.h**

```c
module map;

void scale(inout dataset<f32> values) on compute;
```

**map.b**

```c
module map;

void scale(inout dataset<f32> values) on compute {
    parallel (value in values) {
        value = value * 2.0 + 1.0;
    }
}
```

## Build the DLL

```powershell
bc -c map.b --program scale -o map.obj
blink map.obj -o map.dll
```

The output includes `map.dll`, its import library `map.lib`, and the calling interface used below.

## Write the host

**main.rs**

```rust
#[allow(non_camel_case_types, dead_code)]
#[path = "map.rs"]
mod map;

fn main() -> Result<(), String> {
    let mut values = [1.0, 2.0, 3.0, 4.0];
    let mut program = map::Program::new(map::Backend::Cpu)?;
    program.run(&mut values)?;
    println!("{values:?}");
    Ok(())
}
```

`Backend::Cpu` selects the CPU. `run` borrows the mutable slice synchronously; dropping `Program` releases its handle.

## Compile and run

```powershell
rustc --edition=2024 -C opt-level=3 main.rs -L native=. -o main.exe
.\main.exe
```

Expected output:

```text
[3.0, 5.0, 7.0, 9.0]
```

For deployment, keep `main.exe`, `map.dll`, and any companion DLLs generated by the linker together. Supported types, runtime requirements, and the GPU path are documented in the [integration reference](NativeInterop.md).

For the native Rust SDK and resident resources, see the [native API example](../../sample/interop/README.md#rust-原生-api).
