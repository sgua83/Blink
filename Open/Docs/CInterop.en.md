# Call B from C

[Back to getting started](GettingStarted.en.md#first-dll) · [中文](CInterop.md)

Pass four numbers from C to a B function that computes `value * 2 + 1`, then read the result in the original array. This tutorial covers only the C host.

## Prepare

Complete [installation](GettingStarted.en.md#install), including Rust MSVC and the Windows build tools needed to generate a compute DLL. Open **x64 Developer PowerShell**, create an empty folder, and work there. No repository checkout is needed.

## Write the B computation

Save both files in that folder:

**map.h**

```c
module map;

void scale(inout dataset<f32> values) on compute;
```

**map.b**

```c
module map;

void scale(inout dataset<f32> values) on compute {
    parallel (value in values) {
        value = value * 2.0 + 1.0;
    }
}
```

## Build the DLL

```powershell
bc -c map.b --program scale -o map.obj
blink map.obj -o map.dll
```

The output includes `map.dll`, its import library `map.lib`, and the calling interface used below.

## Write the host

**main.c**

```c
#include "map.abi.h"
#include <stdio.h>

int main(void) {
    float values[] = {1, 2, 3, 4};
    map_handle *program = NULL;
    char error[4096];
    if (map_create(0, &program, error, sizeof(error))) {
        fprintf(stderr, "%s\n", error);
        return 1;
    }
    int result = map_run(program, values, 4, error, sizeof(error));
    map_destroy(program);
    if (result) {
        fprintf(stderr, "%s\n", error);
        return 1;
    }
    for (int i = 0; i < 4; ++i) printf("%.0f ", values[i]);
    puts("");
    return 0;
}
```

`map_create(0, ...)` selects the CPU. `map_run` updates the caller-owned array synchronously; `map_destroy` releases the program handle.

## Compile and run

```powershell
cl /nologo /utf-8 main.c map.lib /Fe:main.exe
.\main.exe
```

Expected output:

```text
3 5 7 9
```

For deployment, keep `main.exe`, `map.dll`, and any companion DLLs generated by the linker together. Supported types, runtime requirements, and the GPU path are documented in the [integration reference](NativeInterop.md).
