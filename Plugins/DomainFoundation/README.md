# DomainFoundation

Integrates the shared BLCluster, BLNode, Supervisor and Admin components for Blink's distributed compilation and execution.

This package is closed source and remains planned. No executable plugin is included yet. Its Windows x64 distribution is reserved for Binaries/windows-x64/BLCluster.exe, BLNode.exe, BLAdmin.exe and BLSupervisor.exe. Other target layouts are listed in the [plugin catalog](../README.md).
